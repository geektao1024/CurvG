# CurvG 导航与内链规范

更新时间：2026-10-15（资源库下线，曲线百科升为一级导航）。定位见 `docs/POSITIONING.md`；本文管"页面之间怎么走"：顶部导航、下拉、面包屑、
页头、内链与外链。新增页面或栏目时按本文检查。

## 1. 页面层级

每个公开页面都属于一个栏目，层级最多三级：

```text
首页 /
├── 实验室 /labs            → 学科 /labs/{math|physics} → 章节 /labs/{suite}[/{chapter}]（沉浸页）
├── 数学奇观 /wonders       → 专题 /wonders/{slug}（沉浸页）
├── 曲线百科 /curves        → 分类 /curves#{category}（同页锚点）→ 曲线 /curves/{slug}
├── 做成视频 /creator       （应用页）
└── 价格 /pricing
```

指南 `/blog → /blog/{slug}`、关键词落地页（`/math-animation-tool`、`/free-math-video-creator`、`/manim-alternative`）
和法律页只从页脚进入。

`/library/**` 已于 2026-10-15 下线，旧地址由 `src/routes/library/-redirects.ts` 301 到同一搜索意图的页面
（曲线类 → `/curves#{category}`，知识点 → 对应实验集或章节），`tests/library-redirects.test.ts` 保证目标存在。

## 2. 顶部导航

- **唯一出处**：`src/blocks/site-nav.ts` 的 `siteNavLinks()`。页头、沉浸页的"导航"菜单、页脚的栏目列都从它生成，
  不要在别处再写一份链接表。
- **一级项**：点击一定进入该栏目的总览页（Hub），不直接跳进某个沉浸页。
- **下拉**（有二级内容的栏目才有）：分组标题链到下一级总览页（如"数学"→ `/labs/math`）；条目链到具体页面；
  底部一行"全部 …"回到 Hub。实验室、数学奇观、曲线百科三个一级项都有下拉；做成视频、价格没有。
  曲线百科的下拉是七个分类（含分形，链到 `/curves#{category}`，注释列该类前三条曲线），底部"全部曲线 · N 条"。
- **当前态**：页面在某栏目下（含其所有子页）时，该一级项高亮（琥珀色加底线）。

## 3. 三种页面外壳

| 外壳   | 用在                                                  | 顶部                                                                                   | 页脚                             |
| ------ | ----------------------------------------------------- | -------------------------------------------------------------------------------------- | -------------------------------- |
| 站点页 | 首页、所有 Hub / 分类页、曲线、指南、价格、落地页     | 站点页头 `Header`（完整导航）                                                          | 有                               |
| 沉浸页 | 实验章节 `/labs/{suite}…`、奇观专题 `/wonders/{slug}` | 紧凑顶栏：Logo → 面包屑 → 页面自己的控件 → **导航菜单**（同一份一级导航）→ 语言 → 账户 | 实验章节无；奇观专题在讲解下方有 |
| 应用页 | `/creator`                                            | 未登录（含会话加载中）：整套站点页外壳（页头、页脚、整页滚动、画框）；登录后：应用侧栏 | 未登录有，登录后无               |

沉浸页的"导航菜单"（`SiteNavMenu`）保证从任何页面都能一步回到任何栏目，交互与站点页头一致。

**画框对齐**：站点页和应用页的内容一律放在 `curvg-stage curvg-frame` 里（最宽 1360px 居中、左右细线），
和页头的画框左右边缘对齐。全宽背景（如奇观的深色渐变）放在画框里面的 section 上，不要让内容跑出画框；
不要把站点页头再包进另一个画框（会被缩进两次）。固定主题的页面（数学奇观）不显示主题切换按钮。

## 4. 面包屑

- 除首页、价格页、关键词落地页和法律页（转化页与单页，不在栏目树里）外，**每个公开页都有可见面包屑**，
  统一用 `PageBreadcrumbs`（沉浸页在顶栏里显示同样的路径，Logo 即首页）。
- 形式：`首页 / 栏目 / 下一级 / 当前页`，当前页不加链接；路径与第 1 节层级一致。
- 结构化数据统一用 `breadcrumbJsonLd()`（`src/lib/seo.ts`），第一项总是首页，和可见面包屑一一对应。

## 5. 总览页页头

所有 Hub / 分类页的首屏用同一个 `PageHero`：面包屑 → 眉标（等宽小字）→ H1 → 一句说明 → 可选的搜索或计数。
左对齐。奇观 Hub 用深色版本（`tone="dark"`），其余用纸面。价格页和首页是转化页，保留自己的版式。

## 6. 内链

每个详情页至少有三类链接：

1. **向上**：面包屑。
2. **横向**：同栏目的相邻内容（实验章节的上一章/下一章、章节栏；奇观无序号导航，靠 Hub）。
3. **跨栏目**（按 `POSITIONING.md` 的分工，两边互链）：
   - 实验章节 → 曲线百科、**相关奇观**（引用了这一章的奇观）；
   - 奇观专题 → 课本里的对应实验（`relatedLabs`）；
   - 曲线 → 相关实验、相关奇观；
   - 所有内容页 → 做成视频（转化）。

页脚按导航的栏目分列：实验室｜数学奇观｜曲线百科（七个分类）｜创作（做成视频、价格、常见问题、落地页）｜指南（含外链）｜法律。

## 7. 外链

- 站外链接一律新窗口打开，`rel="noopener noreferrer"`；导航和页脚的外链由 `isExternalHref` 自动处理。
- 资料来源（维基百科等）放在内容页末尾"资料"处，不进导航。
- 不链竞品；借鉴来源只记在 `docs/`。

## 8. 新增页面检查表

1. 属于哪个栏目、第几级？路径符合第 1 节。
2. 用对外壳（第 3 节）；总览页用 `PageHero`。
3. 有可见面包屑和 `breadcrumbJsonLd`，两者一致。
4. 有向上、横向、跨栏目三类内链；新栏目要同时出现在 `siteNavLinks()`、页脚、sitemap、`llms.txt`。
5. 中英文都检查一遍当前态高亮和移动端菜单。
6. 1440 与 1920 宽度下内容左右边缘与页头画框对齐；390 宽度下页面没有横向滚动。
