## 产品判断

CurvG 不应该被定义成普通的“文本生成视频”工具。更合理的产品核心是：

1. 公式和数学结构是事实来源。
2. AI 负责把数学意图拆成场景计划和可执行代码。
3. 用户可以检查公式、分镜和代码。
4. 渲染在隔离环境执行，并保留可复现的输入与产物。
5. 公开画廊负责内容发现、模板复用和 SEO。

## 目标用户

- 需要制作数学短视频的内容创作者。
- 需要展示函数、参数曲线和几何过程的教师。
- 希望快速生成 Manim 场景但仍需要检查数学正确性的开发者。
- 需要可复用数学动画模板的教育产品团队。

## 核心用户路径

### 画廊路径

`首页 → 浏览曲线 → 查看公式与参数 → 复用模板 → 创建自己的版本`

### 生成路径（已在生产跑通）

`输入公式/意图 → 结构化解析 → 场景计划 → 代码检查 → 沙箱渲染 → 预览 → 导出`

## 产品边界

- 不承诺 AI 输出绝对数学正确。
- 不在 Workers 进程内直接执行用户或模型生成的代码。
- 不把视频二进制存入 D1。
- 没有真实渲染成本数据前不发布套餐价格。
- 竞品截图只作为研究资料，不复制其品牌、文案或受保护素材。
