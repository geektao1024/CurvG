## 2. 定位（2026-10 重定位）

CurvG 是一个**数学工具站**，两半互相导流：

1. **免费交互实验 `/labs`**：一个知识点一块能拖动的画板，配引导步骤、讲解和随堂检测。
   承担获客：每一章都是可被搜索收录、可分享的页面。
2. **AI 数学动画生成器 `/creator`**：把实验、曲线或一个想法做成配音讲解视频；
   公式、场景方案和 Manim 代码全程可检查，不是黑盒的"文字生成视频"。承担转化。

曲线百科 `/curves`、资源库 `/library`、指南 `/blog` 和三张关键词落地页围绕这两半做搜索与发现。

产品判断（沿用）：公式和数学结构是事实来源；AI 负责把数学意图拆成可检查的场景与代码；
渲染在隔离环境执行并保留可复现的输入与产物。

## 3. 目标用户

| 用户           | 主要任务                                 | 入口                  |
| -------------- | ---------------------------------------- | --------------------- |
| 中学与大学教师 | 课堂上演示一个概念、投屏时圈画、出小测   | `/labs` → 做成视频    |
| 学生与自学者   | 动手拖一拖，看懂导数、三角函数、圆锥曲线 | 搜索 → `/labs` 章节页 |
| 数学内容创作者 | 做讲解短视频，要求公式和画面准确         | `/creator`、`/curves` |
| Manim 使用者   | 省掉场景规划和渲染环境                   | `/creator`、落地页    |

## 4. 核心用户路径

- **实验 → 视频**：搜索进入章节页 → 拖动画板 / 跟着引导走一遍 → 顶栏或文末「做成视频」→
  `/creator` 预填提示词 → 登录后渲染。
- **百科 → 视频**：`/curves/{slug}` 调参数 → 「生成这条曲线的动画」→ `/creator`。
- **生成路径**（已在生产跑通）：`输入公式/意图 → 六阶段规划 → 可编辑规格 → 确定性编译 Manim → 沙箱渲染 → 预览 → 导出`。
- **站内互链**：章节页「继续探索」链到相关实验、曲线百科、资源库主题；资源库 Hub/主题页和
  曲线详情页反向列出相关实验。

## 6. 视觉与品牌

"纸面与琥珀"，全站与实验页同一套：暖米纸面、墨色文字、深琥珀主色（满足 AA 对比度）、
亮琥珀做图形点缀；标题 Noto Serif SC，大号序号 Instrument Serif 斜体，标签 JetBrains Mono。
Logo 是一笔画成的 G，起点是琥珀色圆环把手（实验画板上"可拖动的点"）。规范见
`docs/DESIGN_SYSTEM.md` 文首；分享图与封面由脚本生成（`pnpm og:labs`、`pnpm og:brand`）。

## 7. 当前状态

已在生产：双语站点、账号与计费底座、Creator 六阶段规划、确定性编译、Sandbox 渲染、R2 产物、
曲线百科与落地页（2026-08）。

仍未完成：

- **生成可用性**：2026-10 排查时生产生成基本不可用——DeepSeek 在知识阶段输出被截断，
  Kuaipao 额度耗尽。需决定默认模型切换或充值（见 `docs/ANIMATION_ORCHESTRATION.md`）。
- **实验 → 视频**的 B 方向：用实验的引导步骤（参数关键帧 + 旁白）直接驱动视频，而不是只预填提示词。
- 实验内容：按 `docs/LABS_PLAN.md` §6 继续补，物理首批 3 个实验集和数学「函数与微积分」8 章、「圆锥曲线」4 章已齐，数学还差几何 3 章、概率 4 章。
- 首页主关键词：title 仍是 2026-08 的生成器词，要不要换成实验类词需先查关键词数据。
- 资源库场景页 `/library/scenes/{slug}`、公开画廊、作品编辑器。
- SymPy 级数学验证、真实渲染成本数据与定价验证。

## 8. 产品边界

- 不承诺 AI 输出绝对数学正确；实验里讲解提到的数字由测试钉住（`tests/labs-content.test.ts`）。
- 不在 Workers 进程内执行用户或模型生成的代码；不把视频二进制存入 D1。
- 竞品（wedulab、mathos、animg 等）只借表现形式与机制，不复制品牌、文案或素材；
  借鉴时要按 CurvG 工具站定位调整，而不是逐像素照搬。
- 法律页面仍是工程初始化文本，正式收费或开放上传前需按实际主体重新审阅。

### 2026-10-13（夜）— 数学「圆锥曲线」补齐 4 章，内容按第一性原理复查

- 新增 3 章：椭圆的定义、抛物线与焦点弦、双曲线与渐近线。每章从轨迹定义出发（距离之和、到焦点与准线距离相等、距离之差），画板实时量出定义里的距离，方程、b² = a² − c²、焦半径、焦点弦长、渐近线都在讲解区由定义推出。
- 章节顺序改为"三个定义 → 离心率统一"，`/labs/conics` 打开的第一章因此由离心率换成椭圆（站点尚未部署，没有旧链接受影响）。
- 复查已有章节，补上三处只给结论、没给理由的地方：指数函数斜率 (aˣ)′ = aˣ ln a 按差商推出；导数判单调性补上中值定理；弹簧振子周期补上代入验证。

### 2026-10-13（晚）— 数学「函数与微积分」补齐 8 章

- 新增 4 章：指数与对数、正弦型函数 y = A sin(ωx + φ)、单调性与极值、零点与二分法，按教材顺序插进原来的 4 章之间，数学学科共 10 章。
- 二分法把每一次对半展开成一对标量（共 10 步），测试拿普通循环逐步核对区间端点；单调性章节的切线按 f′ 的正负变色，并在 x 轴上画出增减区间。

### 2026-10-13（下午）— 物理「机械波」实验集

- 新增 3 章：机械波的传播、波的叠加与干涉、多普勒效应，物理学科共 11 章，学科页标题承诺的"运动、力与能量、振动与波"都有了内容
