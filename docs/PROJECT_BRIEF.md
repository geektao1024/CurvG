## 2. 定位（2026-10 重定位）

> 定位总纲见 `docs/POSITIONING.md`（2026-10-14：看得见、玩得动、导得出；学科边界；实验室与数学奇观的分工）。
> 本节与它冲突时以它为准。

CurvG 是一个**数学工具站**，两半互相导流：

1. **免费交互实验 `/labs`**：一个知识点一块能拖动的画板，配引导步骤、讲解和随堂检测。
   承担获客：每一章都是可被搜索收录、可分享的页面。
2. **AI 数学动画生成器 `/creator`**：把实验、曲线或一个想法做成配音讲解视频；
   公式、场景方案和 Manim 代码全程可检查，不是黑盒的"文字生成视频"。承担转化。

曲线百科 `/curves`、资源库 `/library`、指南 `/blog` 和三张关键词落地页围绕这两半做搜索与发现。

产品判断（沿用）：公式和数学结构是事实来源；AI 负责把数学意图拆成可检查的场景与代码；
渲染在隔离环境执行并保留可复现的输入与产物。

## 3. 目标用户

| 用户           | 主要任务                                 | 入口                  |
| -------------- | ---------------------------------------- | --------------------- |
| 中学与大学教师 | 课堂上演示一个概念、投屏时圈画、出小测   | `/labs` → 做成视频    |
| 学生与自学者   | 动手拖一拖，看懂导数、三角函数、圆锥曲线 | 搜索 → `/labs` 章节页 |
| 数学内容创作者 | 做讲解短视频，要求公式和画面准确         | `/creator`、`/curves` |
| Manim 使用者   | 省掉场景规划和渲染环境                   | `/creator`、落地页    |

## 4. 核心用户路径

- **实验 → 视频**：搜索进入章节页 → 拖动画板 / 跟着引导走一遍 → 顶栏或文末「做成视频」→
  `/creator` 预填提示词 → 登录后渲染。
- **百科 → 视频**：`/curves/{slug}` 调参数 → 「生成这条曲线的动画」→ `/creator`。
- **生成路径**（已在生产跑通）：`输入公式/意图 → 六阶段规划 → 可编辑规格 → 确定性编译 Manim → 沙箱渲染 → 预览 → 导出`。
- **站内互链**：章节页「继续探索」链到相关实验、曲线百科、资源库主题；资源库 Hub/主题页和
  曲线详情页反向列出相关实验。

## 8. 产品边界

- 不承诺 AI 输出绝对数学正确；实验里讲解提到的数字由测试钉住（`tests/labs-content.test.ts`）。
- 不在 Workers 进程内执行用户或模型生成的代码；不把视频二进制存入 D1。
- 竞品（wedulab、mathos、animg 等）只借表现形式与机制，不复制品牌、文案或素材；
  借鉴时要按 CurvG 工具站定位调整，而不是逐像素照搬。
- 法律页面仍是工程初始化文本，正式收费或开放上传前需按实际主体重新审阅。

### 2026-10-13（凌晨）— 数学新增「概率与统计」4 章，§6 首批规划完成

- 新实验集 `probability`：排列与组合、二项分布、正态分布与 3σ、大数定律。数学学科共 20 章，全站 31 章、7 个实验集。
- 没有新开资源库分类，沿用 §6.1 的做法挂到已有分类：排列组合、二项分布 → `numbers-structure`（计数）；正态分布 → `accumulation`（概率即面积）；大数定律 → `series-limits`（极限）。
- 读数都由画板自己算：组合数用逐位相乘再除以 k!，与只用加法搭出的杨辉三角对照；二项分布的总和、均值、方差按柱子求和量出；正态分布的区间概率用辛普森公式做数值积分（48 条），测试拿 erf 级数独立核对。
- 大数定律的数据是固定种子（mulberry32，20261013）预先跑好的 1000 组 × 1000 次模拟记录，写进章节文件；测试重新跑一遍逐个核对。画板引擎没有随机数和循环，这是目前唯一的办法。

### 2026-10-13（深夜）— 数学「几何与证明」补齐 4 章

- 新增 3 章：圆周角定理、相似与位似、向量加法与数量积。数学学科共 16 章，全站 27 章。
