# CurvG 定位（总纲）

更新时间：2026-10-14。本文是定位的唯一出处：做什么、不做什么、内容放哪一栏、新题目怎么判断。
其他文档（`PROJECT_BRIEF.md`、`LABS_PLAN.md`、`WONDERS_PLAN.md`、`SITE_ARCHITECTURE_PLAN.md`）
与本文冲突时以本文为准；要改定位，先改本文并在文末"决策记录"里写一条。

## 1. 一句话

> **CurvG：把数学变成看得见、玩得动、导得出的动画。**
>
> CurvG turns math into animations you can watch, play with, and export.

| 动词 | 栏目                           | 作用                         | 视觉                       |
| ---- | ------------------------------ | ---------------------------- | -------------------------- |
| 看   | 数学奇观 `/wonders`            | 门面、分享、视频素材         | 深色舞台                   |
| 玩   | 实验室 `/labs`                 | 内容规模、搜索长尾、老师复用 | 纸面与琥珀（浅色）         |
| 导出 | 做成视频 `/creator` 与讲解视频 | 付费点                       | 跟随来源（奇观出片为深色） |

曲线百科 `/curves`、资源库 `/library`、指南 `/blog` 是围绕这三块的搜索与发现入口，不是独立的产品线。

名字 CurvG 读作 curve + graph：用户对它的预期是"曲线和图像"。所有内容都要能回到这个预期。

## 2. 学科边界：能用公式算出来的才做

**规则**：一个题目的核心，必须能写成公式、曲线或确定的规则，并由我们的引擎实时算出来、画出来。

- **数学**：主体，没有限制。
- **物理**：只收"数学是主角"的题目（运动学、振动与波、轨道、混沌、场线）。物理是数学的应用场景，不是第二个学科品牌，
  不进主口号。
- **其他学科**（生物、化学、天文观测、地理、经济、AI 科普）：现在不做。个别题目如果本质是一条公式或一个算法
  （例如神经网络决策边界、萤火虫同步的振子模型），按上面的规则单独判断，并放在"数学奇观"里从数学角度讲。

**为什么**：

1. 名字是 CurvG，不是"世界的形状"。泛学科会稀释名字，和 shapeof.world、PhET 正面竞争而没有优势。
2. 我们的长处是"数学上是对的"（精确求值、确定性动画、测试钉住每个数字），这也是和通用 AI 视频的区别。
   只能画示意图的题目用不上这个长处。
3. 付费点是数学动画，泛科普流量转化不到付费上。

## 3. 两种内容的分工

|          | 实验室 `/labs`                    | 数学奇观 `/wonders`                         |
| -------- | --------------------------------- | ------------------------------------------- |
| 回答什么 | 课本里的一个知识点怎样成立        | 一个"为什么会这样"的现象                    |
| 用户来源 | 搜具体知识点（"导数的几何意义"）  | 好奇心、分享（"傅里叶 画圆""为什么……"）     |
| 编排     | 学科 → 实验集 → 章节，跟课标      | 编号排列的独立专题                          |
| 形态     | 画板 + 引导步骤 + 讲解 + 随堂检测 | 自动播放的动画故事 → 交给读者自己玩         |
| 成本     | 低：声明式画板配置，一天可出多章  | 高：每个专题手写场景代码                    |
| 节奏     | 按实验集成批做，追求数量          | 一到两周一个，追求每个都能剪成一条好短视频  |
| 出口     | 相关章节、做成视频                | 回到课本里的对应实验（`relatedLabs`）、视频 |

### 新题目怎么归类

1. 用户会把它当作课本知识点去搜、去学 → **实验**。
2. 它是值得看的现象，看完会问"为什么" → **奇观**。
3. 两者都占（例如傅里叶级数）→ 实验讲推导和练习，奇观讲现象；两页互链，标题和目标关键词错开，
   **同一个搜索意图只有一个主页面**。
4. 过不了第 2 节的规则 → 不做。

## 4. 品牌一致性

两种视觉，同一个品牌：

- 共用 Logo、衬线标题（Noto Serif SC）、等宽标签（JetBrains Mono）。
- 琥珀色"笔尖点"（实验画板上可拖动的点、奇观里圆链末端的点）在两边都出现。
- 奇观专题页顶栏始终有 CurvG 品牌和回到实验室的入口；实验室不出现深色舞台元素。
- 视觉规则见 `docs/DESIGN_SYSTEM.md`（浅色）与 `docs/WONDERS_PLAN.md`（深色）。

## 5. 不做的事

- 不做泛学科知识宇宙；不按 shapeof.world 的学科分类扩张。
- 不做学生拍照解题（Mathos、Gauth、Photomath 的赛道）。
- 不在页面上承诺还没上线或在生产上跑不通的能力。
- **不直接搬竞品的代码、文案、海报、品牌**：可以借鉴交互形式和选题方向，实现与文案必须自己写（见第 6 节）。

## 6. 借鉴竞品与开源项目的规则

| 来源                    | 许可                                                | 我们能做什么                                                    |
| ----------------------- | --------------------------------------------------- | --------------------------------------------------------------- |
| shapeof.world 代码      | `AGPL-3.0-only`                                     | 只作参考。复制进 CurvG 会让整个站点须按 AGPL 向所有用户公开源码 |
| shapeof.world 文案/海报 | `CC BY-NC 4.0`（禁止商业使用）                      | 不能用。CurvG 有付费订阅，属于商业使用                          |
| shapeof.world 品牌      | 保留                                                | 不能用名称、Logo、视觉标识                                      |
| 其中的第三方部分        | 各自许可（如字体 OFL-1.1、黑洞着色器 BSD-3-Clause） | 按各自许可单独判断，从原始出处引入并署名                        |
| wedulab、mathos 等      | 闭源                                                | 只借鉴交互和信息架构                                            |

公式、定理、物理规律和选题本身不受著作权保护；我们按公式从头实现，不逐行改写对方代码。
要直接使用 AGPL 代码，只有两条路：整站按 AGPL 开源，或向权利方（自由维度（深圳）科技有限公司）购买商业授权。
