# CurvG 设计系统 —— 黑板宇宙（定案）

> 本文档是全站前端样式与交互的唯一真相来源。所有 UI 决策以此为准。
> 决策过程：苏格拉底式需求澄清 + 四方向样式实验室实物对比（2026-07），用户最终裁决：**方向 B 黑板宇宙**。

## 一、设计哲学（已锁定的根决策）

| 根问题           | 决策                                     | 含义                                                       |
| ---------------- | ---------------------------------------- | ---------------------------------------------------------- |
| 3 秒内的核心情绪 | **敬畏——数学之美**                       | 深色黑板底色，数学是主角，界面是承载板书的黑板             |
| 唯一的签名交互   | **曲线活在界面里**                       | 一条实时演化的"粉笔曲线"是整站的灵魂资产                   |
| 动效的本质作用   | **解释因果**                             | 动效只用于状态转换、空间关系、注意力引导；零装饰动效       |
| 视觉隐喻         | **黑板宇宙**                             | 整站像一块无限延伸的深色黑板，曲线是粉笔笔迹               |
| 目标用户         | 教育者 / 学生 / YouTube 创作者，海外市场 | 墨绿黑板底自带"学习安全区"的集体记忆，色温偏暖、低视觉疲劳 |

### 一句话概括

> **整站是一块写满数学的宇宙黑板：墨绿的底、粉笔白的字、薄荷色的重点标记。个性压在"粉笔曲线"和手迹感上，骨架保持完全常规易用。**

### 三条不可违背的红线

1. **只有一个主角**：任何页面同时只能有一条"活的曲线"。两条曲线互相抢戏 = 违规。
2. **动效必须有信息量**：每个动效必须能回答"它解释了什么因果"。回答不了就删。
3. **骨架不许实验**：导航、表单、按钮、布局全部遵循最常规的模式。手迹感（微旋转、虚线边框）只是表皮装饰层，信息结构必须无损。

## 二、色彩系统

### 主题策略

**深色即正典**：黑板宇宙的深色不是"暗色模式"，而是产品本身。全站默认且主要为深色。浅色适配（长文阅读）为后续迭代项，优先级低。

### 色板（5 个颜色角色）

| Token                 | 值                          | 角色                                                      |
| --------------------- | --------------------------- | --------------------------------------------------------- |
| `--background`        | `#101815`（墨绿黑板）       | 黑板本体。绿黑而非纯黑，自带教室记忆与低疲劳色温          |
| `--foreground`        | `#f2f0e6`（粉笔白）         | 正文与板书。暖调 off-white，比纯白柔和                    |
| `--primary`           | `#7dd8c0`（薄荷粉笔）       | 唯一主色：曲线标记、链接、焦点态、主按钮                  |
| `--card` / `--border` | `#16211d` / 粉笔白 14% 透明 | 卡片底、分隔线。边框常用 2px 虚线（dashed），像粉笔框线   |
| `--accent`            | `#e8c477`（琥珀粉笔）       | 次强调：手写标注、审批/确认时刻、评分徽标。出现频率 < 10% |

辅助中性色：`--muted-foreground: #8a9589`（黑板上的浅灰绿，用于次要文字）。

### 粉笔质感规格（签名资产）

- 曲线本体：粉笔白 `#f2f0e6`，双遍抖动描边叠加（外层 2.2px @ 50% 透明 + 内层 1.2px @ 75% 透明），模拟粉笔的颗粒虚边
- 追踪点/标注：琥珀 `--accent` 小圆点
- **克制原则**：粉笔纹理只属于曲线和少量手写标注。按钮、卡片、正文一律不加纹理——舒服感来自色温而非噪点，这也控制了维护成本
- 手迹装饰词汇表（全站统一，不许发明新的）：`border-dashed` 虚线边框、±1deg 以内微旋转、`decoration-dashed` 虚线下划线、琥珀色手写体标注

### 浅色适配（未来项）

长文页（百科/博客）如需浅色阅读模式，隐喻从"黑板"切换为"纸张"：暖白底 `#faf8f2` + 墨绿文字，曲线变为深色实线笔迹。未排期，不要提前实现。

## 三、字体系统

严格 2 个字族（现有配置保持）：

| 用途      | 字体                                     | 说明                                                        |
| --------- | ---------------------------------------- | ----------------------------------------------------------- |
| 标题      | **Libre Baskerville**（serif，斜体为主） | 板书标题的古典手写感。用 `italic` 强化"书写"隐喻            |
| 正文      | **Inter**                                | 可读性优先，正文永不使用衬线或手写体                        |
| 数学/代码 | ui-monospace 栈                          | 行内公式记号、参数值。LaTeX 由 KaTeX 渲染（不计入字族预算） |

排版规则：

- 正文 `leading-relaxed`，最小 14px
- 首屏标题 `text-5xl sm:text-6xl` 衬线斜体；不用超大字号嘶吼
- 标题 `text-balance`，正文段落 `text-pretty`

## 四、布局与空间原则

- **每屏一件事**：营销页每个 section 只讲一个论点
- **垂直节奏**：section 间距 `py-24 md:py-32`；内容最大宽度 `max-w-6xl`，长文 `max-w-2xl`
- **Flexbox 优先**，复杂二维布局才用 Grid；禁止绝对定位堆砌（唯一例外：曲线画布层）
- **移动优先**：所有布局从 375px 开始设计
- **首页首屏为左右布局**：左侧标题 + 副标题 + CTA，右侧粉笔曲线画布。移动端纵向堆叠（文字在上、曲线在下）

## 五、签名交互："粉笔曲线" 完整规格

组件：`src/components/living-curve.tsx`（`renderStyle="chalk"`）。分级实现：

### L1 首页主角曲线

- Hero 右侧画布中一条实时演化的粉笔曲线，在形态族（利萨茹 → 玫瑰线 → 蝶形 → 内摆线）间连续插值
- 琥珀色追踪点沿曲线移动，像"正在书写的粉笔头"
- 形态切换用参数空间插值，不是透明度淡入淡出

### L2 过程即曲线（工作台）

- 渲染排队/进行中：进度可视化为"正在被粉笔描绘的曲线"
- 规格审批通过：一次性琥珀"划重点"脉冲（0.2s）——全站唯一庆祝动效

### L3 百科页的活标本

- `/curves/[slug]` 页首是该曲线的交互式版本：拖参数滑块实时重算，公式对应系数同步高亮

### L4 降级策略

- `prefers-reduced-motion`：静态最终形态，动画关闭（组件已内置）
- 低端设备：降低采样点数与抖动遍数
- 无 JS / 爬虫：服务端内联静态 SVG，SEO 内容完整可索引

## 六、动效准则（解释因果）

| 场景                                    | 动效                               | 时长      |
| --------------------------------------- | ---------------------------------- | --------- |
| 页面导航切换                            | 无过渡（速度即尊重）               | 0         |
| 状态机跃迁（draft→spec→code→rendering） | 阶段指示器沿路径推进               | 300ms     |
| 展开/折叠                               | 高度 + 透明度                      | 200ms     |
| 焦点/悬停                               | 颜色/边框即时变化；卡片微旋转归正  | 100-150ms |
| 曲线形态演化                            | 时间驱动连续插值                   | —         |
| 审批通过                                | 琥珀划重点脉冲（全站唯一庆祝动效） | 200ms     |

禁止清单：背景粒子、呼吸光效、悬浮微动、视差装饰、打字机效果、骨架屏闪光之外的加载动画。

## 八、实现注意事项

- 主题 token 定义于 `src/styles/globals.css`，`:root` 即黑板宇宙深色正典（深色不是 `.dark` 变体，是默认值）
- `<html>` 挂 `bg-background`，避免任何闪白
- 曲线组件 `src/components/living-curve.tsx` 供 L1-L3 复用，props 契约：`color` / `secondaryColor` / `renderStyle`
- 性能预算：曲线渲染 ≤ 4ms/帧；曲线画布不参与 LCP，延迟到主要内容绘制后初始化

## 九、验收标准

1. 用户打开首页 3 秒内读懂"这是在黑板上做数学动画的工具"
2. 全站任意页面截图拼在一起，色板/字体/手迹词汇表完全一致
3. `prefers-reduced-motion` 用户获得完整功能与完整内容
4. Lighthouse 移动端 Performance ≥ 90
5. 任何新增动效都能在 code review 中回答"它解释了什么因果"
6. 手迹装饰只使用第二节词汇表中的四种手法，不许发明新的
