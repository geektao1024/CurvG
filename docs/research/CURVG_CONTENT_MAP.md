## 借鉴与差异

| 竞品可借鉴点                    | CurvG 处理方式                                         |
| ------------------------------- | ------------------------------------------------------ |
| 深青色 + 高亮绿色的数学工具视觉 | 使用 `#001e2b`、`#00ed64`，但重新设计版式、Logo 和内容 |
| 公式、代码、预览并列            | Hero 同时显示参数公式和确定性 SVG 预览                 |

## 页面叙事

1. 产品是什么：数学曲线动画画廊与生成器。
2. 为什么可信：预览直接由公式采样生成。
3. 能发现什么：不同曲线家族和数学概念。
4. 准备怎么生成：结构化输入、检查场景、隔离渲染。
5. 当前能做什么：明确初始化状态和未完成部分。
6. 如何参与：申请早期访问。
