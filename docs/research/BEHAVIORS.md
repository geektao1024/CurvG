# CurvG 首页行为

更新时间：2026-07-22

## 导航

- 首页 Header 不固定，随页面离开视口；内部画布高度为 `80px`。
- Gallery、Workflow、FAQ 使用同页锚点。
- 主要 CTA 跳转 `/sign-up`，使用双像素箭头裁切轨道。
- 移动端使用折叠菜单，点击链接后自动关闭。

## 像素交互

- 主 CTA 的箭头由五个方块组成，默认显示轨道第二份，Hover/键盘聚焦切换到第一份。
- 该切换模拟目标站的 `flex-end → flex-start` 裁切机制，不使用普通 Lucide 箭头平移。
- 竞品的流程 Hub、旋转状态徽标不移植到首页；它们与 CurvG 的公式曲线展示冲突。

## 曲线预览

- Hero 利萨如曲线由公式采样 241 个点。
- 路径循环执行描边动画，不改变公式采样结果。
- `prefers-reduced-motion: reduce` 时停止动画并展示完整曲线。
- 画廊四张卡片全部由 TypeScript 公式生成 SVG path。

## 响应式

- `< 640px`：单列 Hero、单列画廊、单列工作流。
- `640px–1023px`：Hero 单列，画廊双列。
- `≥ 1024px`：Hero 左文案右预览，工作流三列。

## 主题

- 支持浅色和深色主题。
- 数学预览画布始终使用深青色，保证曲线颜色一致。
- Header 保留语言和主题切换入口。

## 可访问性

- 所有曲线 SVG 提供本地化 `aria-label`。
- 纯品牌图标使用空 `alt`，相邻文字提供品牌名。
- 交互按钮保留键盘焦点和语义链接。
