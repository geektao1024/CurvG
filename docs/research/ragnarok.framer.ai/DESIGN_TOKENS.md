# Ragnarok 首页设计令牌

采集页面：<https://ragnarok.framer.ai/>  
采集基准：桌面视口 `1440 × 1000`，2026-07-22。

## 已验证令牌

| 类别         | 值                     | 用途                            |
| ------------ | ---------------------- | ------------------------------- |
| 页面背景     | `#f3f3f9`              | 页面、导航、主要分区            |
| 主文字       | `#201f32`              | 标题、主按钮                    |
| 强调色       | `#262ef2`              | 动态标题、图标、状态节点        |
| 次级文字     | `#4d5564`              | 正文与说明                      |
| 边框         | 约 `#e3e2e5`           | 画框、分栏、卡片                |
| 标题字体     | `Space Grotesk`, `500` | H1/H2/H3                        |
| 正文字体     | `Inter`, `400`         | 正文、导航、按钮                |
| 微型界面字体 | `Geist` / `Inter`      | 模拟产品 UI 内部的 10–13px 文本 |

## 字体比例

- 桌面 H1：`52px / 52px`，`font-weight: 500`，`letter-spacing: -0.52px`。
- 1280px 附近 H1：`44px`，保持约 `1` 的紧行高。
- 区块 H2：`48px / 52.8px`，`font-weight: 500`。
- 卡片 H3：`24px / 26.4px`，`font-weight: 500`。
- 正文：`18px / 25.2px`；卡片说明多为 `16px` 左右。

## 画布几何

- 1440px 视口下，主体画框从 `x=40` 到 `x=1400`，宽 `1360px`。
- 左右各保留 `40px` 纹理侧轨，侧轨不是空白 margin，而是细密斜线层。
- 导航高 `80px`；首屏主体从 `y=80` 到约 `y=680`。
- 主体大量使用 `1px` 分割线、50/50 分栏和重复的角落定位点。
- 背景层依次为：冰白底色 → 斜线侧轨 → 主画框边线 → 分区网格线 → ASCII/点阵动画装饰 → 内容。

## 实现取舍

- CurvG 保留自己的曲线内容和交互画布，不复制 Ragnarok 的品牌资产。
- 使用 CSS 生成侧轨、网格、定位点和光晕，不下载竞争对手的标志或插图。
- 视觉优先级是边界、间距、字体和层级；阴影与大圆角仅用于需要浮层感的 UI 模拟。
