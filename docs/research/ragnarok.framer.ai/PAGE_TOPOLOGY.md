# Ragnarok 首页拓扑

1. **80px 导航**：品牌、文本导航、登录/注册/联系操作；随正常文档滚动离开视口。
2. **双栏 Hero**：左侧动态标题与 CTA，右侧多层 AI 工作流动画；底部紧接品牌信任条。
3. **功能总览**：居中章节标记、48px 标题、左右 ASCII 点阵装饰。
4. **2 × 2 功能画布**：四个大面积分栏面板，每格包含独立产品动画。
5. **How it Works**：标题后接三个纵向步骤，文本与产品 UI 左右交替。
6. **对比矩阵**：左侧标题，右侧横向对比表。
7. **价格、证言、数据、FAQ**：继续沿用 1360px 画框与 1px 分割系统。
8. **移动端宣传与深色 CTA**：深色背景用于制造唯一的高对比高潮。
9. **多列页脚**：回到浅色画框体系。
