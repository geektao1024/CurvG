# Header + Hero Spec

## Header

- 高度 `80px`，桌面与主体同宽。
- 非 sticky；滚动后离开视口。
- 背景与页面一致，无玻璃模糊。
- 导航文字使用 Inter 16px 左右，悬停只做轻微透明度变化。

## Hero

- 桌面高度约 `600px`，左右各 50%。
- H1 使用 Space Grotesk 500，`clamp(44px, 3.6vw, 52px)`，行高 `1`。
- 动态强调文本使用 `#262ef2`，字符级输入和删除。
- 右侧为分层场景；CurvG 保留点阵、细网格、坐标读数和 `LivingCurve`，不移植竞品的 AI 流程 Hub。
- 主按钮采用 `#201f32`、白字、约 `5px` 圆角；箭头使用两份五格像素图形的裁切轨道。
- Hero 底部增加四格状态条，延续目标站信任条的横向分格节奏。
