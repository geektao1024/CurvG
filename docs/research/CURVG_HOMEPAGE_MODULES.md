# CurvG 首页模块映射

更新时间：2026-07-23

## 结论

参考 `animo.video/zh` 与 `animg.app/zh-CN` 后，CurvG 首页新增三个模块：

1. **公式优先工作台预览**：解释 CurvG 的核心不是“输入一句提示词后黑箱出视频”，而是公式、场景规格、代码和预览可以分别检查。
2. **适用人群**：面向教师、学习者、内容创作者，说明各自的数学动画任务；不声称已有客户或案例。
3. **当前能力边界**：把已可见的公式画廊与页面基础，同计划中的场景生成、Sandbox 渲染明确区分。

## 竞品取舍

| 竞品模块                      | 观察                                   | CurvG 决策                                                             |
| ----------------------------- | -------------------------------------- | ---------------------------------------------------------------------- |
| Animo：文本描述 → 实时视频    | 直观展示从想法到动画的过程             | 采用“工作台预览”，但以公式和场景规格为事实来源，不假装当前已有实时视频 |
| Animo：轻量客户端、下载和价格 | 适合桌面软件的转化                     | 不采用；CurvG 当前没有可发布的客户端、定价或成本数据                   |
| AnimG：Creator 工作台         | 能清晰呈现对话、规格、代码、视频的结构 | 采用静态产品示意，并链接现有 `/creator`；不在首页触发 AI 或渲染请求    |
| AnimG：示例库 / 社区作品      | 需要真实作品、作者和交互数据支撑       | 当前只保留现有公式曲线画廊；不伪造社区、喜欢数或作者资料               |
| AnimG：多种适用场景           | 有助于让用户快速自我识别               | 采用三类人群，但用“面向 / 用于”表述，不承诺未实现能力                  |
| 两站的 FAQ                    | 用来清楚解释能力边界                   | 保留并扩展现有 FAQ；其中内容必须与当前实现保持一致                     |
