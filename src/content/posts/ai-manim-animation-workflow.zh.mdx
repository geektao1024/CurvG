AI 做 Manim 动画，有用的前提是画面上的数学是对的。导数算错的漂亮视频，比没有视频更糟。所以 CurvG 不让大模型每次从零写一整段动画：AI 只做一件小事，挑一个验证过的模板、填好参数，剩下的交给我们写好、测过的代码。

**要点：** 在 CurvG，AI 从 12 个验证过的模板里挑一个并填参数；画面上的每个数都在渲染前用代码算好；每个视频都附带 Manim Community 源码。模板以外的题目走自由生成，它还是测试版，可能算错。

## AI 生成 Manim 动画，到底生成的是什么？

它不是用文字直接画出视频。[Manim Community](https://docs.manim.community/en/stable/tutorials/quickstart.html) 是一个 Python 引擎：一段动画就是一个 `Scene`，在 `construct()` 方法里添加对象、播放动画，再由 Manim 渲染出每一帧。所以任何"AI 做 Manim"的工具，最后产出的都是交给 Manim 运行的 Python 代码。

这段代码有两种来法：

1. **AI 写整段场景。** 每个对象、坐标、标签和时间点都为这一次请求重新生成。
2. **AI 选一个现成的场景。** 模板是一段测过的场景，留出参数（函数、区间、矩形个数），AI 只负责填参数。

CurvG 的付费视频全部走第二种，第一种保留为测试版。

## 为什么用模板，而不是让 AI 写场景？

因为从零写的场景每次都是一段新程序。里面任何一个对象、坐标或时间点都可能出错，一个数错了整段视频就废了，而自动的数学检查只能抓到一部分错误。

模板把这件事倒过来：

- **数学是算出来的，不是生成出来的。** 模板在搭场景之前，就用 TypeScript 把要显示的数（导数、黎曼和、根、行列式）算好。算不准的值，比如函数在这一点不可导、积分发散，会在你花钱之前直接拒绝并说明原因。
- **每个参数只过一道门。** 表单、AI 的选择、站内其他页面带过来的链接，都在服务端过同一套校验，每次渲染前再过一遍。
- **同样的参数，每次得到同样的视频。** 时间点落在固定的网格上，渲染器会拿成片和计划的时长逐帧核对。

## 一个题目怎么变成视频？

### 第 1 步：说你想讲什么

像上课时那样说就行："x³ − 3x 在 x = 1 处的切线""x² 从 0 到 2、8 个矩形的黎曼和""行列式为 −1 的 2×2 矩阵怎么把平面翻过来"。也可以从[实验章节](/labs)或[曲线](/curves)出发：很多章节和曲线会直接打开对应模板，参数已经填好，根本不经过 AI。

### 第 2 步：AI 挑模板、填参数

这是一次很小、很快的请求。结果和表单过同一道参数校验，模板拍不准的请求会被拒绝并说明原因，而不是硬拍一段错的。

### 第 3 步：检查参数

你会看到这个模板的表单：可以改函数、区间、点的位置、矩形或谐波的个数、画幅（16:9 或 9:16）和主题（浅色或深色）。渲染之前，浏览器里有一张实时草图，显示会画出什么。

### 第 4 步：渲染

由 Manim Community 在云端渲染出 MP4。讲解以画面字幕呈现，中文或英文，没有配音。每个验证过邮箱的账号有 3 个免费预览视频（720p，带水印）；1080p 无水印视频消耗积分（[定价](/pricing)），免费预览以后也能导出成高清。渲染失败会退还积分。

### 第 5 步：代码归你

每个视频都附带 Manim Community 源码，可以查看、复制、下载。浏览器里不能改，但可以在你自己的 Manim 环境里运行和修改。

## 哪些题目有模板？

| 模板       | 视频讲什么                                   | 你来设                 |
| ---------- | -------------------------------------------- | ---------------------- |
| 函数图像   | 函数的截距、零点和极值点                     | f(x)、x 范围           |
| 二次函数   | 开口、配方、对称轴、判别式与根               | a、b、c                |
| 函数变换   | a·f(b(x − h)) + k 一步一步变出来             | f(x)、a、b、h、k       |
| 导数与切线 | 割线逼近切线，斜率读数落到 f′(a)             | f(x)、a                |
| 黎曼和     | 矩形从 1 个到 n 个，和收敛到定积分           | f(x)、a、b、n、取样点  |
| 积分的累积 | 面积函数 A(x) 与微积分基本定理               | f(x)、a、b             |
| 单位圆     | 圆上的点画出正弦或余弦波                     | sin 或 cos、圈数       |
| 泰勒级数   | 泰勒多项式逐步逼近，以及收敛半径             | 六个函数之一、最高次数 |
| 傅里叶级数 | 正弦谐波拼出方波、锯齿波或三角波，吉布斯现象 | 波形、谐波数           |
| 参数曲线   | 动点描出 x(t)、y(t)                          | x(t)、y(t)、t 范围     |
| 极坐标曲线 | 射线扫出 r(θ)，包括 r < 0 的部分             | r(θ)、θ 范围           |
| 线性变换   | 2×2 矩阵让网格变形，î、ĵ、单位正方形和行列式 | a、b、c、d             |

12 个模板都是二维的。几何证明、统计和三维曲面暂时还没有模板。

## 没有合适的模板怎么办？

请求会交给自由生成，由 AI 从零写场景。它会跑一遍自动数学检查，但检查只提醒、不拦截：发现问题时，你会看到警告，自己决定要不要用。它可能失败，也可能算错，所以自由生成的视频拿去上课之前，请先完整看一遍。渲染失败同样退还积分。

## 怎么写请求，才能准确对上模板？

写清数学对象和数字，不要写风格：

- **好：** "sin(x) 在 x = π/4 处的导数，用切线表示。"模板和两个参数都很清楚。
- **好：** "方波的傅里叶级数，7 个谐波。"
- **含糊：** "来一段很酷的微积分动画。"AI 只能去猜函数、点和模板。

如果你的题目和某个模板接近但不完全一样，说清楚最在意哪一部分；AI 会挑最接近的模板，渲染前你还可以改参数。

## 用视频之前要检查什么？

- **你要的是不是这个。** 不管给什么函数和区间，模板都会算对，所以最常见的错误是函数打错了。
- **看不看得清。** 字幕会自动缩放到画面里，但长公式放在 9:16 的竖屏里会变小。要在手机上用，两种画幅都试试。
- **自由生成的警告。** 带警告的测试版视频，要一句一句仔细看。

## 常见问题

### AI 能保证数学动画是对的吗？

单靠 AI 不能。CurvG 的模板视频里，AI 只负责挑模板和参数；画面上的数由代码算出，参数经过校验，所以数学的可靠程度取决于模板本身。自由生成的视频是 AI 写的，可能出错。

### 需要会 Python 吗？

不需要。描述题目，或者填模板的表单就行。想看或想接着改，Manim 源码都在。

### CurvG 每次都能出视频吗？

有模板的题目，能；除非渲染本身失败，那时会退还积分。自由生成的测试版请求可能失败。

### 能改 Manim 代码吗？

浏览器里不能。下载下来，在你自己的 Manim 环境里改。

### CurvG 会取代 Manim Community 吗？

不会。每个 CurvG 视频都是用 Manim Community 渲染的。CurvG 是独立产品，与 Manim Community 或 3Blue1Brown 没有关联。
